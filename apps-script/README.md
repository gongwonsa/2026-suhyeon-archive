# Apps Script 설치와 배포

지도교사 구글 계정으로 한 번만 하면 됩니다. 시트 주소, 웹 앱 주소, 접속 코드는 이 저장소에 적지 않습니다.

## 1. 스프레드시트 만들기

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. 이름은 자유입니다.
2. 이 시트는 누구에게도 공유하지 않습니다. "웹에 게시"도 하지 않습니다.

## 2. 코드 붙여 넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 왼쪽 **프로젝트 설정(톱니바퀴)**에서 "편집기에 'appsscript.json' 매니페스트 파일 표시"를 켭니다.
3. 편집기의 `appsscript.json` 내용을 이 폴더의 `appsscript.json`으로 바꿉니다.
4. `Code.gs` 내용을 이 폴더의 `Code.gs`로 바꿉니다.
5. 저장합니다.

## 3. 시트 탭 만들기

1. 편집기 위쪽 함수 목록에서 `setupSheets`를 고르고 **실행**을 누릅니다.
2. 권한 요청이 나오면 교사 계정으로 허용합니다. "이 시트만 보고 편집" 권한 하나만 요청합니다.
3. 시트에 `works`, `work_edits`, `consents`, `genres` 탭과 숨김 탭 `html_files`가 생기고 장르 6개가 들어갑니다. 이미 쓰던 시트라면 빠진 열과 탭만 추가됩니다.
4. 시트를 새로고침하면 상단에 **전시 관리** 메뉴가 생깁니다. 처음 누를 때 "시트에 메뉴 표시" 권한을 한 번 더 허용합니다.

## 4. 웹 앱 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형은 **웹 앱**을 고릅니다.
3. 실행 계정은 **나**, 액세스 권한은 **모든 사용자**로 둡니다.
4. 배포 후 나오는 `https://script.google.com/macros/s/.../exec` 주소를 복사합니다. 주소에 `/u/1/`처럼 `/u/숫자/`가 들어 있으면 그 부분을 지웁니다. 여러 계정에 로그인한 브라우저에서만 쓰는 주소라 다른 사람은 열 수 없습니다.
5. 브라우저에서 주소 끝에 `?action=public`을 붙여 열면 `{"ok":true,"works":[],"genres":[...]}`가 보여야 합니다.

## 5. 접속 코드 정하기

1. 시트 상단 **전시 관리 → 접속 코드 변경**을 누릅니다.
2. 새 코드를 4~50자로 입력하고 확인을 누릅니다.
3. 원문은 어디에도 저장되지 않습니다. 잊으면 새로 정하면 됩니다. 바꾸면 이미 입장한 학생은 다시 입장해야 합니다.
4. 학생에게는 수업 자료로 알려 주고, 주소나 QR 코드에는 넣지 않습니다.

## 6. 사이트에 주소 연결

- 내 컴퓨터: 프로젝트 폴더의 `.env.local`에 `VITE_APPS_SCRIPT_URL=복사한_주소`를 적습니다.
- GitHub 배포: 저장소 **Settings → Secrets and variables → Actions → Variables**에 이름 `APPS_SCRIPT_URL`, 값 `복사한_주소`로 추가합니다.

## 코드를 고친 뒤

1. 편집기에서 `Code.gs`와 `appsscript.json`을 이 폴더의 최신 내용으로 바꾸고 저장합니다.
2. 권한이 늘어난 경우 함수 목록에서 `setupSheets`를 한 번 실행해 새 권한을 허용합니다.
3. **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 누릅니다. 이렇게 해야 웹 앱 주소가 바뀌지 않습니다. "새 배포"를 다시 만들면 주소가 바뀝니다.

## 운영 중에

- 공개 여부는 `works` 탭의 `status` 열을 `공개`, `숨김`, `대기`, `삭제요청` 중 하나로 바꿉니다.
- 사이트 반영은 최대 5분 걸립니다. 바로 반영하려면 **전시 관리 → 사이트에 바로 반영**을 누릅니다.
- `id`, `work_no`, `work_type`, `html_ref` 열은 바꾸지 않습니다. 숨김 탭 `html_files`(HTML 작품 본문)도 직접 고치지 않습니다.
- 작품을 완전히 지울 때는 `works` 행과 같은 `work_id`의 `consents`, `work_edits` 행을 지웁니다. `html_files`의 행은 지우지 말고 내용만 비우세요. 다른 작품의 위치가 바뀌기 때문입니다.
